## Runtime contract

1. Team/build validation permits each promoted compatible Mega Stone as a held item and Item Clause still applies.
2. Command submission accepts `mega: true` only on a move action from an active, living, compatible stone holder.
3. The turn resolver runs switch actions, then Mega transformations, then dynamically ordered moves.
4. Transformation preserves damage taken, PP, status, stages and volatiles; recalculates level-50 stats; swaps identity, types, explicit height/weight, sprite key and active Ability; recompiles passive effects, then resolves Ability Start hooks for the new form (for example Drought).
5. The public event exposes the new form and Ability only when transformation resolves.
6. The transformation persists after switching and the side cannot Mega Evolve again.
