## Kiến trúc đang hoạt động

- `app/local-server.mjs`: HTTP + WebSocket qua Node/ws; xử lý quyền sở hữu, hàng đợi action, lưu state và gửi view. Hoạt động local, mặc định cổng 3100.
- `app/server/storage-json.mjs`, các module migration/release: persistence và tương thích save. Không chỉnh trực tiếp `.local-data` khi phát triển.
- `app/logic-src` → `app/src/logic.js`, `app/src/v2-engine.mjs`: code sinh tự động cho phần nền/compatibility v1-v2; sửa fragment và compile, không sửa file generated.
- Battle hiện tại là schema 3: `app/server/v3-battle-actions.mjs` điều phối; `app/rules-v3` sở hữu battle state, phase, target, thứ tự action, RNG và event; `app/mechanics-v3` sở hữu các handler move/Ability/item và tương tác mechanics.
- Server nhận command kèm phase revision, kiểm tra lựa chọn, resolve cả người chơi/AI rồi phát event và snapshot. Queue có thể dừng cho replacement và tiếp tục phần còn lại. Settlement dùng receipt để tránh cộng thưởng trùng.
- Catalog: `content-active/active.json` trỏ beta-slice-v35, kiểm SHA-256; `server/v3-mega-catalog.mjs` ghép `content-src/mega-beta-v8.json`; foundation bổ sung dữ liệu form.
- Client: `public/client.js` ghép store/router/net và các màn v3; screen modules phụ trách Training, Team Builder, Archive, Recruitment, Battle.
- Input: `GameUiController`, `InputManager`, `FocusManager`, `UiModeStack`; command handler có các bước COMMAND → MOVE → TARGET/PARTY → REVIEW. Move có một target có thể chọn tự động.
- Presentation: event → turn frames → presentation plan/timeline → DOM/CSS/audio. `V3PlaybackRunner` điều khiển tốc độ/cancel; commit tại cue tương ứng, không tự tính damage thay engine.
- `pixel-era-ui.css` được nạp cuối, ghi đè UI cũ; phong cách xanh/kem, viền vuông, cursor vàng, menu ngang. Đây vẫn là DOM/CSS trên mặt phẳng logic 1280×720, không phải renderer pixel 320×180 thực sự.
- `GameViewportScaler` uniform-fit; ảnh dùng resampling auto thay vì ép nearest-neighbour toàn bộ.
