# Batch — secure full ZIP + resource icons + available ticket/box registry

- Current `public/assets/icons/{vp,pokegem,bag}.png` are used for the topbar, Shop VP balance and Shop Owned filter. The existing recruitment ticket is also displayed in the topbar. Resource icons in Mailbox and Missions share the same renderer.
- `public/js/reward-assets.js` maps **only** the files currently present: 4 ticket assets and 5 rank-reward boxes. `scripts/validate-reward-assets.mjs` checks asset names, PNG integrity and transparency. It is included in `npm run check`.
- Common/Rare/Legendary, VP, and PokéGem **box images are not in this repository yet**, and no unapproved reward/drop/opening mechanics were added. `rankBoxAsset(rank)` is a display-only resolver for later development, not an entitlement or inventory API.
- The `.dev.vars.example` file defaults `AUTH_ALLOW_LOCAL_BETA=false`. To use Local Beta authentication **locally**, explicitly set it to `true` in your private `.dev.vars`; do not ship that file. Keep `ADMIN_ALLOW_LOCAL_BETA=false` unless intentionally testing administration locally. Never use Local Beta login on a public deployment.
- `npm run package:full -- --output /path/to/filename.zip` produces the full source + checked-in assets and existing dependencies. It does not include local `.dev.vars`, `.env*` (other than safe examples), `.local-data`, keys, logs or cached runtime state. It does not rotate leaked keys: if a prior ZIP was shared, rotate the credentials and invalidate affected sessions.
- `npm run check:syntax` parses all source modules in one Node 22 process (no source execution); `npm run check:fast` validates this batch rapidly; `npm run check` and `npm test` are the release checks. Broad `npm test` passed 1,222/1,222 tests across 174 files in this batch. A green gate does not replace a manual 2-player network/reconnect browser smoke test.
